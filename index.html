UAV Mission Toolkit

v0.1 · early development

Architecture Coordinate frames File formats

Four small, self-contained tools for preparing UAV missions. Everything runs locally in the browser: there is no backend, no build step and no database. Files are read from and written to your machine, and nothing is uploaded anywhere.

Coordinates are handled in one place: WGS84 latitude/longitude for the site origin, a local ENU frame in metres for everything else, and headings in degrees clockwise from true north. Altitudes always travel with an explicit reference (AGL, AMSL or ATO); the toolkit never guesses one.

Tools

Site Editor

Define an operating site on a map and export it as a generic site definition.

  • Origin, safety polygon and altitude limits
  • Mission points, draggable on the map
  • Live validation, no hidden defaults
  • Download site.json

Site Viewer

Read-only look at a site definition for sanity checking before a flight.

  • Origin, safety area and mission points
  • Local ENU and WGS84 coordinates side by side
  • Dimensions, area and altitude band
  • The same validation rules as the editor

Trajectory Editor

Sketch a path in the local plane and export it in a documented, generic format.

  • Straight, circle, racetrack and figure-eight presets
  • Draggable control points
  • Altitude, target speed, path length and duration
  • Download JSON or CSV

Altitude Sweep

Produce altitude variants of a trajectory and prove nothing else moved.

  • Start, end and step altitude
  • Per-variant preview
  • Round-trip verification of every generated file
  • Individual or bulk download

Running it

The tools use ES modules and fetch, so they need to be served over HTTP. Opening the files directly with file:// will not work. 

python3 -m http.server 8000
# then open http://localhost:8000

Example data

The repository ships one fictional demo site under examples/, listed in examples/manifest.json. Its coordinates and geometry were invented for this repository and do not correspond to any real operating location.

Scope

This is early, experimental software for preparing and inspecting mission data. It is not a flight-safety system, it does not talk to any vehicle, and nothing it produces should be flown without independent review. See SECURITY.md.
