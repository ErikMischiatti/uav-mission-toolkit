UAV Mission Toolkit

Local mission preparation · v0.1

Architecture Coordinate frames File formats

Four tools for preparing UAV missions on your own machine: define an operating site, design a trajectory inside it, and generate verified altitude variants of that trajectory.

Everything runs in the browser — no backend, no build step, no database, and nothing is uploaded. The site origin is WGS84 latitude/longitude; everything else is metres in a local ENU frame, with headings in degrees clockwise from true north. Altitudes always carry an explicit reference (AGL, AMSL or ATO); the toolkit never guesses one.

Workflow

Step 1

Site Editor

Define where you are allowed to fly, and the points you care about.

  • Origin, safety polygon and altitude limits
  • Mission points, draggable on the map
  • Validation as you edit, with no hidden defaults

out: site.json
→
Step 2

Trajectory Editor

Sketch a path in the local ENU plane and export it in a documented, generic format.

  • Straight, circle, racetrack and figure-eight presets
  • Draggable control points
  • Path length and a constant-speed duration estimate

out: trajectory.json / .csv
→
Step 3

Altitude Sweep

Produce one variant per altitude, and prove nothing else moved.

  • Start, end and step altitude
  • Per-variant preview
  • Every generated file is parsed back and compared to the source
  • Only a variant that passes can be downloaded

in: trajectory.csv · out: one CSV per altitude

Inspection

Any time

Site Viewer

A read-only look at a site definition, for checking one before a flight. It runs the same validation rules as the editor and never modifies the file.

  • Origin, safety area and mission points on a map
  • Local ENU and WGS84 coordinates side by side
  • Dimensions, area, perimeter and altitude band

in: site.json

Running it

The tools use ES modules and fetch, so they have to be served over HTTP. Opening the files with file:// will not work. There is nothing to install. 

python3 -m http.server 8000
# then open http://localhost:8000

Example data

One fictional demo site ships under examples/, indexed by examples/manifest.json. Its coordinates and geometry were invented for this repository and do not correspond to any real operating location.

Scope

This is early, experimental software for preparing and inspecting mission data. Its validation findings are planning aids, not flight certification: it provides no certified geofencing, no terrain model, no collision avoidance and no flight authorisation. It does not talk to any vehicle. Nothing it produces should be flown without independent review — see SECURITY.md.
